# Asset sources

- `neil-armstrong.glb`: detailed Neil Armstrong Apollo suit model, model-viewer shared assets: https://modelviewer.dev/shared-assets/models/NeilArmstrong.glb . Original collection: Smithsonian 3D, https://3d.si.edu/ . Preserve source attribution and consult the original asset's usage terms before redistribution.

- `astronaut.glb`: model-viewer shared astronaut asset, downloaded from https://modelviewer.dev/shared-assets/models/Astronaut.glb . Source project: https://github.com/google/model-viewer/tree/master/packages/shared-assets . Retain the upstream astronaut model's attribution and license when redistributing.
- Earth day, normal and cloud maps: Three.js example planet textures, https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets . Source imagery credited by the upstream project; retain upstream notices when redistributing.

Boat, fortress, city, Ferris wheel, terrain and shoreline meshes are generated locally.
The `*-realistic.glb` models and coastal PBR textures are authored and baked with
the Python sources in `blender/`; see `blender/REALISM.md` for rebuilding them.
